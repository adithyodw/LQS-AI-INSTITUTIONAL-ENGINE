LQS Institutional Flow Engine is a professional-grade Expert Advisor built on
a 5-module signal fusion architecture. It identifies high-probability reversal
setups by detecting institutional liquidity sweeps, confirming with order flow
analysis, validating through Wyckoff market structure, and filtering with
Anchored VWAP and Volume Profile confluence.

Designed for XAUUSD (Gold) on the H1 timeframe.

---------- HOW IT WORKS ----------

The EA combines five independent market analysis modules into a unified
signal scoring system. A trade is only executed when multiple modules
confirm the same directional bias with sufficient confidence.

Module A — Liquidity Sweep Detection
Identifies stop hunts and liquidity grabs at key price levels: previous day
high/low, Asian session range, swing pivots, round numbers, and session
opens. Measures wick percentage, volume ratio, reversal strength, and
sweep depth to score each event.

Module B — Order Flow Analysis
Approximates institutional order flow using synthetic delta from candle
structure. Detects volume divergences, absorption patterns (high volume
with small range), exhaustion signals, and buying/selling pressure
imbalances using both fast (8-bar) and slow (configurable) windows.

Module C — AMD Wyckoff Cycle
Implements the Accumulation-Manipulation-Distribution model on the higher
timeframe. Detects spring and upthrust patterns, volume climaxes, and
phase transitions. Identifies when manipulation ends and distribution
begins, providing directional context for entries.

Module D — Anchored VWAP
Calculates Volume Weighted Average Price anchored to seven key points:
Asian session, London open, New York open, weekly open, daily open,
swing pivots, and Point of Control. Detects VWAP clusters, premium and
discount zones using standard deviation bands, and level alignment
with sweep events.

Module E — Volume Profile
Builds a rolling volume profile to identify Point of Control (POC),
Value Area High/Low (VAH/VAL), High Volume Nodes (HVN), and Low Volume
Nodes (LVN). These zones serve as institutional support and resistance
for stop loss placement and target identification.

---------- SIGNAL FUSION ENGINE ----------

Each module produces an independent score (0-100). The fusion engine
combines them using configurable weights:

  SignalScore = wA*ModuleA + wB*ModuleB + wC*ModuleC + wD*ModuleD + wE*ModuleE

A trade executes only when:
- SignalScore exceeds the entry threshold (default: 50)
- A minimum number of modules confirm (default: 3 of 5)
- Directional consensus is achieved (voting system)
- A confirmed liquidity sweep has occurred
- EMA 50/200 trend filter aligns (configurable)

---------- RISK MANAGEMENT ----------

- Kelly Criterion position sizing with configurable fraction
- ATR-based dynamic stop loss (default: 2.5x ATR)
- Three-tier take profit: TP1 (1.5 ATR), TP2 (3.0 ATR), TP3 (5.0 ATR)
- Automatic partial close at TP1 and TP2 (33% each)
- Breakeven move after 1R profit
- ATR-based trailing stop
- Daily loss limit (default: 3%)
- Daily profit lock (default: 8%)
- Peak equity drawdown protection (default: 8%)
- Maximum spread filter
- Trade cooldown between entries
- Maximum daily trades limit

---------- EXECUTION ENGINE ----------

- Automatic broker fill type detection (FOK/IOC/RETURN)
- Order retry logic (3 attempts on requote)
- Slippage protection
- ECN/STP compatible
- Single-chart operation (no multi-chart required)

---------- ADDITIONAL FEATURES ----------

- Market regime classification (Strong Trend/Weak Trend/Range/High Volatility)
- Regime-adaptive module weights
- Economic calendar news filter (USD and EUR high-impact events)
- Real-time on-chart dashboard displaying all module states
- Weekend and session-time filters
- Fully optimizable in MT5 Strategy Tester
- Custom optimization criterion (Sharpe * PF * sqrt(Trades) * RecoveryFactor)
